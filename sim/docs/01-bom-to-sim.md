# BOM → 仿真参数推导

本文记录 `gz_extras/` 里每一个数字的来源，方便以后换桨、换电池、加载荷时重新标定。
所有实机数据取自 `BOM.xlsx` 的「BOM 物料清单」与「重量与续航评估」两张表。

## 1. 质量

BOM 起飞总重 **3576.7 g**（含 1 块 6S 6800mAh，930 g；另一块只是备用，不装机）。

| 分区 | 小计 (g) | 仿真去向 |
|---|---|---|
| 裸机（机架/电机/电调/桨/飞控/GPS/电池/数传/接收机） | 3115.5 | `base_link` |
| 计算载荷（载板/Orin Nano/335L/散热/WiFi/SSD/电容） | 331.2 | `base_link` |
| 装配余量（线材/螺丝/支架/减震球） | 130.0 | `base_link` |
| **合计** | **3576.7** | |

旋翼 link 单独计 **4 × 90 g = 360 g**（桨 + 电机转子/桨夹；MN4014 定子算在机架里），于是

```
base_link = 3.5767 - 4 × 0.09 = 3.2167 kg
```

`make check` 会验证 `base_link + Σrotor = 3.5767 kg`（容差 ±10 g）。

## 3. 电机标定（核心）

### 3.1 映射关系

PX4 输出归一化油门 `u ∈ [0,1]`，Gazebo 侧按 airframe 的 `SIM_GZ_EC_MIN/MAX` 换成角速度：

```
ω = EC_MIN + u · (EC_MAX − EC_MIN)
T = k · ω²                 （单电机推力，N）
```

`EC_MAX` 必须等于 `model.sdf` 里 4 个插件的 `maxRotVelocity`，否则推力曲线整体缩放错，
`make check` 的 `[2]` 项就是查这个。

### 3.2 两个参数怎么定

用 BOM 台架的两端点（100% → 1920 g）和悬停点（53.0%）反解：

```
满油门： k · EC_MAX² = 1920/1000 × 9.81 = 18.835 N
悬停：   ω_hop = sqrt(894.175/1000 × 9.81 / k)
         u_hop = (ω_hop − EC_MIN)/(EC_MAX − EC_MIN) = 0.530
```

取 `EC_MIN = 150 rad/s`（怠速，与上游 x500 同值），解得 `EC_MAX = 460 rad/s`（≈4420 rpm，
对 KV330 @ 6S、15×5 桨是合理负载转速），于是

```
k = 18.835 / 460² = 8.9012e-05
```

### 3.3 与台架的偏差

| 油门 | 台架 (g) | 仿真 (g) | 偏差 |
|---:|---:|---:|---:|
| 50% | 830 | 844.1 | +1.7% |
| 65% | 1150 | 1121.1 | −2.5% |
| 75% | 1430 | 1327.5 | −7.2% |
| 85% | 1690 | 1551.4 | −8.2% |
| 100% | 1920 | 1920.0 | 0.0% |

**为什么中高油门偏低**：Gazebo 的推力严格 ∝ ω²，而真实 ESC 的「油门→转速」在中高段更陡
（台架 50% 就有满推力的 43%，纯二次模型只给 25%）。本方案用「怠速偏置 + 限定最大转速」
把 50% 点和 100% 点钉死，中段自然偏低。

**要不要修**：不需要。避障/航点验证用的是控制响应和几何，不是绝对推力；真要拟合曲线，
阶段 2 可用二次多项式形式 `T = a·u² + b·u + c`（把 `multicopter-motor-model` 换成
自定义 `LiftDrag` 或改用 `motorType=pwm` + `thrust_curve`），代价是偏离上游实现。

### 3.4 力矩系数

| 参数 | 值 | 依据 |
|---|---|---|
| `momentConstant` | 0.0305 | 全油门 Q/T = 264 W / 460 rad/s ÷ 18.835 N = 0.574/18.835 |
| `rotorDragCoefficient` | 1.25e-3 | 同上的 Q/ω = 0.574/460 |
| `rollingMomentCoefficient` | 1e-6 | 沿用上游 |

这两个只影响偏航力矩与阻力矩的量级，数值取自 BOM 的 264 W/电机功率。

## 4. 惯量 / 质心

**方法**：把 19 类部件按 BOM 的质量与装机位置逐个当 box / 点质量，用平行轴定理加总
（`scripts/09_estimate_params.py`，可复现）。

| 项 | 值 | 说明 |
|---|---|---|
| 总质量 | 3576.7 g | 与 BOM 一致 |
| 质心 | (+0.93, +0.07, **−1.44**) cm | 电池下挂 → z 为负；335L 在机头 → x 为正 |
| Ixx | **0.0924** kg·m² | 旧箱体估算 0.1240，**偏大 25%** |
| Iyy | **0.0979** kg·m² | 旧 0.1240，偏大 21% |
| Izz | **0.1591** kg·m² | 旧 0.2265，偏大 30% |

> 之前用 0.65×0.65×0.20 m 均质箱体，会**高估**惯量：真实质量集中在中心
> （电池 930 g 在腹部、飞控/载板在中间），机臂是空心细管，质量并不铺满 0.65 m 见方。
> 模型里已同步写回 `inertial` 的 `<pose>`（质心偏移），不止是数值。

**不确定度**：±10–15%（装机位置与配重是我的假设，BOM 只有总重）。
**更准的做法**：整机装好后用双线摆法测 `Izz`、换水平轴吊测 `Ixx/Iyy`，精度可到 ±3–5%。

## 6. 仿不出来的东西（别指望它）

| 实机 | 仿真 | 影响 |
|---|---|---|
| 6S 6800mAh 电池（内阻、压降、放电曲线） | 只有理想质量 | **续航不能靠仿真**，仍用 BOM 的 15.2 min 设计值 |
| Jetson Orin Nano 算力/功耗/结温 | 无 | 3DVFH* 只能在本机 CPU 上跑，算力预算要另外实测 |
| Gemini 335L 双目视差、强光、IP65 | 单目深度缓冲 | 深度精度/盲区与真机不同 |
| SiK 数传 / ELRS 链路 | UDP（14550） | 链路延迟、丢包、失控保护不能靠仿真验证 |
| 磁干扰（电机/大电流） | 无 | 建议真机做罗盘校准与电流干扰测试 |
| **电机失效注入** | 无 | gz-sim 8.15 **没有** `MotorFailurePlugin`（模型里已删掉这条死引用），要做失效实验得自己写插件或直接改 `motorConstant` |
| 风 | 未启用（`enable_wind=false`） | 加 `gz-sim-wind-effects-system` + link 的 `enable_wind` 才能做抗风实验 |

> 当前飞行是「无风 + 理想模型 + 传感器噪声」，落点误差 2.6 cm 应理解为精度**下界**。

## 7. 换参数时改哪里

| 改动 | 文件 | 注意 |
|---|---|---|
| 换电池/加载荷 | `x650_base/model.sdf` 的 `base_link/mass` | 同步 `scripts/05_check_model_math.py` 的 `BOM_TAKEOFF_MASS_KG` |
| 换电机/桨 | `x650/model.sdf` 的 `maxRotVelocity`、`motorConstant` | 同时改 airframe 的 `SIM_GZ_EC_MAX`，跑 `make check` |
| 换轴距 | `x650_base` 的 rotor `pose` + airframe 的 `CA_ROTOR*_PX/PY` | 两边必须成比例（0.508L / 0.859L） |
| 换悬停油门目标 | airframe 的 `MPC_THR_HOVER` | 只影响控制器前馈，不影响物理 |

## 9. 参数来源与不确定度（汇报时优先看这张表）

| 参数 | 当前值 | 来源 | 方法 | 不确定度 | 想更准怎么做 |
|---|---|---|---|---|---|
| 质量 3576.7 g | ✅ 精确 | BOM 逐件累加 | 称重/清单 | < 1% | 装机后整机称一次 |
| 质心 (+0.9, +0.1, −1.4) cm | 估算 | 装机布局假设 | 平行轴加总 | ±2 cm | 三点称重法 |
| Ixx/Iyy/Izz 0.0924/0.0979/0.1591 | 估算 | 同上 | 分部件平行轴 | ±10–15% | 双线摆（±3–5%） |
| 单电机满推力 1920 g | 台架 | T-Motor MN4014 官方数据 | 5 点台架 | ±3% | 自建拉力台 |
| 推力曲线形状 | k·ω² | gz 插件固定形式 | 2 参数拟合 | **中段 8%** | 换自定义 lift 插件 |
| 悬停油门 53% | 台架推算 | BOM「重量与续航」 | 插值 | ±2% | 飞行实测 |
| 电池内阻/放电 | 未建模 | — | — | — | 恒流放电 + DCIR |
| Cd·A | 未建模 | 文献值 0.1–0.2 m² | 经验 | ±30% | 风洞/飞行辨识 |
| IMU 噪声 | 沿用 x500 | 器件手册（IIM42653 等） | 上游模型 | 同量级 | 静置 Allan 方差 |

**推力曲线为什么只做到 8%**：gz 的 `MulticopterMotorModel` 固定 `T = k·ω²`，
油门到转速是仿射映射，只有两个自由度；台架曲线（50% 就已经是满推力的 43%）
比二次曲线“更平”。三种拟合方案的结果：

| 方案 | EC_MIN | EC_MAX | 最大偏差 | 悬停油门 | 特点 |
|---|---|---|---|---|---|
| 满推力精确（当前采用） | 192 | 560 | 7.7% | 51.7% | 端点准，中段偏 |
| 悬停段加权 | 170 | 515 | 8.1% | 52.6% | 飞行区间准 |
| 三参数无约束 | 134 | 452 | 5.6% | 52.3% | 曲线最贴，但满推力高估 5.6% |

要突破 8%，只能换掉推力模型（自定义 `lift` 插件或查表），不是调参能解决的。
